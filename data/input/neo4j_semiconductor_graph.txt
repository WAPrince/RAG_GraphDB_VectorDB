--- SEITE 1: EINLEITUNG UND SCHEMA-DEFINITION ---
Dieses Dokument dient als umfassende Spezifikation und Datengrundlage für einen
globalen Wissensgraphen im Bereich der Halbleiterindustrie und der Künstlichen Intelligenz.
Die Halbleiter-Lieferkette ist eines der komplexesten wirtschaftlichen Netzwerke der Welt.
Kein einzelnes Land und kein einzelnes Unternehmen kontrolliert den gesamten Prozess vom
Rohstoff (Silizium, Seltene Erden) über die Lithografie (ASML) bis hin zur Fertigung (TSMC)
und dem Chipdesign (NVIDIA, AMD). Diese Datei strukturiert die wirtschaftlichen Verflechtungen,
politischen Restriktionen und technologischen Abhängigkeiten in einer Form, die direkt
in eine Neo4j Graphdatenbank eingelesen werden kann.

GRAPH-SCHEMA DEFINITION:
Knoten-Labels (Nodes):
- Company (Unternehmen: Name, Hauptsitz, Marktkapitalisierung, Kernprodukt)
- Country (Staat: Name, Region, Exportkontrollstatus)
- Technology (Technologie: Name, Kategorie, Entwicklungsstufe)
- Politician (Politiker/Regierungsvertreter: Name, Amt, Land)
- Facility (Fertigungsstätte/Fab: Name, Ort, Kapazität)

Beziehungs-Typen (Relationships):
- SUPPLIES (Liefert Komponenten oder Maschinen an)
- INVESTS_IN (Investiert Kapital in)
- HQ_IN (Hat Hauptsitz in)
- CONTROLS (Übt politische/regulatorische Kontrolle aus)
- MANUFACTURES (Stellt bestimmte Technologien her)
- DEPENDS_ON (Ist technologisch abhängig von)
- REGULATES (Beschränkt oder reguliert Märkte/Unternehmen)

--- SEITE 10: PYTHON AUTOMATION INTERFACE FÜR NEO4J ---
Der folgende Python-Code liest genau dieses Dokument ein, filtert die markierten Datenblöcke
und lädt sie direkt über den offiziellen Neo4j-Treiber in Ihre Graphdatenbank hoch.


import json
from neo4j import GraphDatabase

class Neo4jImporter:
    def __init__(self, uri, user, password):
        self.driver = GraphDatabase.driver(uri, auth=(user, password))

    def close(self):
        self.driver.close()

    def import_from_file(self, file_path):
        with open(file_path, 'r', encoding='utf-8') as f:
            lines = f.readlines()

        nodes_to_create = []
        rels_to_create = []
        
        for line in lines:
            line = line.strip()
            if line.startswith("NODE;"):
                parts = line.split(";", 3)
                label = parts[1]
                node_id = parts[2]
                props = json.loads(parts[3])
                nodes_to_create.append((label, node_id, props))
            elif line.startswith("REL;"):
                parts = line.split(";", 3)
                start_id = parts[1]
                rel_type = parts[2]
                end_id = parts[3]
                rels_to_create.append((start_id, rel_type, end_id))

        with self.driver.session() as session:
            # 1. Knoten erstellen
            for label, node_id, props in nodes_to_create:
                query = f"MERGE (n:{label} {{id: $node_id}}) SET n += $props"
                session.run(query, node_id=node_id, props=props)
            print(f"{len(nodes_to_create)} Knoten erfolgreich geladen.")

            # 2. Beziehungen erstellen
            for start_id, rel_type, end_id in rels_to_create:
                # Da die Endknoten (Länder/Techs) evtl. implizit sind, erstellen wir sie generisch falls nicht vorhanden
                query = (
                    f"MERGE (a {{id: $start_id}}) "
                    f"MERGE (b {{id: $end_id}}) "
                    f"MERGE (a)-[r:{rel_type}]->(b)"
                )
                session.run(query, start_id=start_id, end_id=end_id)
            print(f"{len(rels_to_create)} Beziehungen erfolgreich verknüpft.")
